# Code audit, November 2026 — resolution

An external audit (Antigravity) reported 13 findings. Each was reproduced or checked against the code before changing anything. Fixed in 0.7.4; regression tests in `tests/test_audit_fixes.py` and the Rust unit test in `windows/src/xml.rs`.

| # | Finding | Verdict | Change |
|---|---|---|---|
| 1 | Windows: relationship targets with drive letters or backslashes could read outside the package | Real (Windows only) | `part_path` replaces unsafe segments (`..`, `\`, `:`), so parts can never leave the package folder |
| 2 | macOS: ZIP size limit trusted the declared sizes | Real | Bytes written are watched while extracting; the extraction is stopped above the limit |
| 3 | macOS: duplicate entries (also by case) and `../` paths accepted | Reproduced: a duplicate replaced a slide on disk | Entry names are checked before extracting |
| 4 | Overflow with huge `sldSz` or `sldId` | Reproduced: crash on macOS, wrong result on Windows | Source sizes and IDs are validated before any arithmetic |
| 5 | Verifier missed a missing `[Content_Types].xml`, dropped embedded fonts, and `--verify` after `--size` | Reproduced | Both are issues now; `--verify` accepts `--size` and uses the merge's size plan |
| 6 | macOS expanded DTD entities; Rust had no nesting limit | Reproduced (macOS) | Parts with a DTD are refused in both engines; external entities never load; Rust depth limit 256 |
| 7 | macOS serializer: quotes inside comments | Real, minor (only line breaks inside comments/CDATA changed) | Comments, CDATA and processing instructions are copied verbatim |
| 8 | Error log next to the input; `.report.txt` could overwrite; unverifiable PowerPoint output kept | Real | Log goes next to the output; reports never overwrite; the output is removed if it cannot be checked |
| 9 | Windows: relative paths passed to PowerPoint | Real | Absolute paths are passed |
| 10 | Swift/Rust parity: CRLF, minimum notes font size, non-Latin text width | Real | XML line endings normalised in Rust; minimum 1 pt in both; CJK counted as full-width and more scripts measured |
| 11 | Media held in memory for hashing and zipping | Real | SHA-256 and zipping are streamed |
| 12 | Margins scaled with `sx` when `sx ≠ sy` | Not a bug: content is scaled by one uniform factor; `sx`/`sy` only shift animations | — |
| 13 | Window fitter, settings saved every frame, uninstaller | Window: real (it reset maximised windows). Settings: not true, saved only on change. Uninstaller: real | Fitter leaves maximised and full-screen windows alone; uninstaller removes `%APPDATA%\Deckwright` |

Not addressed: PDF annotation warnings per page on Windows (`Windows.Data.Pdf` does not expose annotations), and complex animation formulas beyond `ppt_x ± n`, which are documented as needing review.
